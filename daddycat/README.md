# Daddy Cat Coffee

Сайт кофейни-антикафе: кофе, настольные игры и стимпанк-интерьер.
React + TypeScript + SCSS на Create React App.

## Запуск

```bash
npm install
npm start     # дев-сервер на http://localhost:3000
npm run build # продакшен-сборка в build/
```

## Структура

```
src/
  assets/       логотип и хелпер путей к фотографиям
  components/
    ui/         кнопка, контейнер, фото, заголовок секции, обёртка появления
    layout/     шапка, подвал, каркас страницы, сброс скролла
    sections/   крупные блоки страниц (обложка, меню, галерея, форма брони)
    cards/      карточки позиции меню, игры и преимущества
  data/         контент: меню, игры, галерея, контакты и афиша
  hooks/        появление блоков при скролле, заголовок вкладки
  pages/        страницы под маршруты
  styles/       переменные, миксины, глобальные стили
```

Каждый компонент лежит в своей папке рядом со своим `.scss`.

## Контент

Тексты, цены, игры и контакты правятся в `src/data/` — вёрстку трогать не нужно.

Фотографии интерьера лежат в `public/assets/photos/` и подключаются по имени файла
(список — в README этой папки). Файлы можно заменить без пересборки; пока снимка нет,
на его месте показывается заглушка с логотипом.

## Дизайн

Палитра снята с интерьера: угольный фон, одна акцентная латунь `#c9962e`,
заголовки Playfair Display, текст Inter. Токены — в `src/styles/_variables.scss`.
Брейкпоинты: 1100 / 860 / 560 px.
